Security Boundary

Fail-closed, not prompt-pink.

Spoiler safety is a database barrier enforced on every read path — not a system prompt suggestion.

spoilerless/app/api/boundary.pyshared resolver
async def resolve_effective_boundary(...):
if not user: return 1 # anon → E01
watched = await progress.get(user.id, series_id)
if not watched: return 1
return min(requested, watched.through_order)

1. Single shared resolver

Every route (/graph, /notes, /revisions, /export, /visualization) goes through resolve_effective_boundary(). Missing progress clamps to 1.

2. Cypher-level filtering

WHERE r.visible_from_order ≤ $order. Future data never leaves Neo4j — browser inspection can't leak it.
