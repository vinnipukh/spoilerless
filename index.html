Platform Capabilities

A Second Brain for Television Narratives.

Spoilerless combines temporal knowledge graph architectures, human-in-the-loop editing, and spoiler-safe GraphRAG into a unified narrative exploration platform.

Fail-Closed Spoiler Safety

Data isolation is enforced at the database query layer. Nodes, relationships, search indexes, and LLM context beyond your selected episode never leave the server.

4 Specialized Projections

Navigate tailored view modes: Story (Overview + Timeline), Characters (Social Network & Conflict), Evidence (Investigation Chains), and Advanced (Full Graph Explorer).

Grounded GraphRAG Chat

Chat with an LLM (Gemini or BYOK OpenAI models) that answers strictly from your spoiler-filtered graph context, quoting verified evidence chips and timestamps.

User Notes & Custom Nodes

Add private notes, custom entities, and custom relationships directly on the graph. User content is visually distinguished from canonical seed facts.

Revisions & One-Click Revert

Every edit, note, or relationship is recorded in an immutable revision history. Compare before/after diffs and roll back any modification safely.

Snapshot Sharing & Export

Create expiring, read-only token snapshot links to share graph perspectives with friends without spoiling future plot twists. Export graph data to clean Markdown.

Security Boundary

Fail-Closed Boundary Defense.

Spoiler safety is not a polite system prompt hint. It is a mathematical database barrier enforced on every read path.

1. Single Shared Resolver

Every route (`/graph`, `/notes`, `/revisions`, `/export`, `/visualization`) passes through `resolve_effective_boundary()`. Anonymous visitors and missing records fail closed to Order 1.

2. Database-Level Filtering

Cypher queries evaluate `WHERE r.visible_from_order <= $order`. Data beyond your watch progress never leaves Neo4j, making browser inspection attacks impossible.

spoilerless/app/api/boundary.py PROD ENFORCEMENT 
async def resolve_effective_boundary(
    graph_service, progress_service, series_id, user, requested_order
) -> int:
    if not user:
        return 1  # Anonymous fails closed

    watched = await progress_service.get_progress(user.id, series_id)
    if not watched:
        return 1  # No progress record fails closed

    return min(requested_order, watched.watched_through_order)
