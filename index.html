Focuses on interpersonal bonds, workplace hierarchies, and antagonistic conflicts. Semantic expansion lets users unfold family or colleague clusters without global relayout.

MATCH (c:Character {id: $node_id}) OPTIONAL MATCH (c)-[r:FAMILY_OF|WORKS_WITH|CONFLICTS_WITH]-(target) WHERE r.visible_from_order <= $order RETURN c, r, target LIMIT 25

Security Boundary

Fail-Closed Boundary Defense

Spoiler safety is not a polite system prompt hint. It is a mathematical database barrier enforced on every read path.

spoilerless/app/api/boundary.py PROD ENFORCEMENT
async def resolve_effective_boundary(graph_service, progress_service, series_id, user, requested_order) -> int: if not user: return 1 # Anonymous fails closed to Episode 1 watched = await progress_service.get_progress(user.id, series_id) if not watched: return 1 # Unwatched series fails closed return min(requested_order, watched.watched_through_order)
1. Single Shared Resolver

Every route (/graph, /notes, /revisions, /export, /visualization) passes through resolve_effective_boundary(). Anonymous visitors and missing records fail closed to Order 1.

2. Database-Level Filtering

Cypher queries evaluate WHERE r.visible_from_order <= $order. Data beyond your watch progress never leaves Neo4j, making browser inspection attacks impossible.
