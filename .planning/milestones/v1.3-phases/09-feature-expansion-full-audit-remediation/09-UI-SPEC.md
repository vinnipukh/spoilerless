## Interaction Contract (Dimension 6)

Global interaction rules for every new/changed surface:

| Concern | Contract |
|---------|----------|
| Keyboard | `⌘K`/`Ctrl+K` opens the command palette (FEAT-08). `/` focuses node search (FEAT-01) when no input is focused and the graph view is active. `Esc` closes palette, search, dialogs, hover card, filter panel, share dialog. `↑`/`↓` + `Enter` navigate all result lists (palette, search, backlinks). `Tab` order follows DOM; all buttons/rows reachable by keyboard. |
| Focus visibility | Every interactive element keeps `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring` (existing pattern). Locked episode pills stay focusable so the unlock flow is keyboard-reachable (PROB-31 must not change this). |
| Motion | All new transitions ≤150ms (existing `transitionMs` convention) except: newly-revealed glow runs 4000ms (FEAT-03), reveal framing runs 2200ms (existing), hover card shows after 120ms delay. `prefers-reduced-motion: reduce` → 0ms transitions, no pulse animation, no animate on fcose. |
| Touch (FEAT-10) | 44px min targets everywhere. Cytoscape touch pan/zoom/tap is native (no pointer-events workarounds). Filter chips and episode pills scroll horizontally on <md (`overflow-x-auto`, hidden scrollbar — existing EpisodeSelector pattern). DetailPanel Sheet is full-width on <md (`w-full sm:w-[420px]`), chat Sheet likewise. GraphControls stays left-bottom on md+, collapses to a single expandable chip stack on <md. |
| Hover | Node hover → existing `.hovered` class + edge highlight, PLUS the FEAT-11 preview card (120ms delay, dismisses on mouseout/Esc, positioned via `cy.getElementById(id).renderedPosition()`). Edge hover → existing width 3.5 + label emphasis. Touch devices: tap = select (no preview card; the card is `md:`-only). |
| Selection | Single-selection dominant + neighborhood fade stays (existing tap handlers). FEAT-06 adds a two-node selection MODE (explicit "Show path" mode — never conflicts with tap-to-select). | Deterministic layout | fcose runs with `randomize: false` and positions cached per `(seriesId, visibleUntilOrder)` (D-04) so a boundary round-trip never re-scrambles the graph. Manual `Reset` (GraphControls) re-runs the layout from the cache, not a random seed. |
| Loading/error/empty | All new views reuse the GraphStatus trio pattern (loading skeletons, destructive Alert + Retry, centered empty state) with the copy from §Copywriting. |
