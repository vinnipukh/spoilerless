<objective>
Fix the three chat/LLM pipeline defects from the audit: mid-stream failures
orphan user messages and vanish from the logs (#35); user notes never reach
the assembled context despite the wired tool (#48); and the provider has an
uncaught JSON parse, dead code, and cost-bloating full tool-result replay
(#52). All verification stays on FakeLLMProvider — zero-cost.

Purpose: Chat failures become visible and non-orphaning; the advertised notes
tool actually influences the model; and the provider handles malformed
streams defensively without paying for duplicated context.
Output: Status-marked chat turns with logged failures, a working notes→context
bridge, and provider edge-case hardening — all FakeLLMProvider-tested.
</objective>
