<objective>
Build the frontend half of the safe graph-editing agent: `ChangeSetCard` rendering the propose-time
preview with per-operation before/after values, destructive-operation warnings, and Confirm/Reject
controls; wiring apply success to an incremental (not destructive) graph refresh that reuses the
focus mechanism from 06-10; and the "Protected" badge for canonical/candidate edit refusals.

Purpose: this closes RAG-14 and RAG-17's ChangeSet-apply half on the frontend, and is the only UI
surface that can ever trigger a graph mutation — its Confirm/Reject controls being the sole
confirmation path (never the chat message itself) is a direct, testable implementation of RAG-14's core
rule.
Output: `ChangeSetCard.tsx`, wired into `MessageList.tsx`; `App.tsx`'s incremental post-apply refresh.
</objective>
