<objective>
Harden every story-sensitive relationship and provenance query at the effective boundary:
relationship-level visibility independent of endpoints (VIS-03/D-10), the
Character/Event -> Claim -> EvidenceFragment -> Source chain gated so a visible Claim never
exposes future Evidence or Source titles (VIS-04/D-11), Notes hidden below their creation
boundary (VIS-05), and Cypher query hardening per D-20.

Purpose: the graph API and the GraphRAG retrieval tools share the same underlying Cypher
patterns (spoiler/filter.py and retrieval/tools.py). Any relationship or provenance element
that leaks past the boundary defeats every other hardening in the phase — counts, search,
chat, and ChangeSets all build on these queries.
Output: hardened queries with fail-closed relationship/provenance gating and the D-23
relationship/provenance/note test matrix.
</objective>
