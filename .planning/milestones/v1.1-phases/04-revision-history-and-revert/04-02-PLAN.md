**Dependencies:** Follow same pattern as user_content.py — `DatabaseDependency`, `Boundary` re-export.

**Routes:**

1. `GET /api/series/{series_id}/revisions` — list revisions
   - Query params: `visible_until_order` (required Boundary), `resource_type` (optional str), `resource_id` (optional str)
   - Returns `list[RevisionResponse]`
   - Executes a parameterized Cypher query that fetches Revision nodes matching series_id, visible_until_order, optional resource_type/resource_id filters
   - Orders by created_at DESC
   - Revisions must have visible_from_order <= visible_until_order
   - If resource_type is provided, filter by it; if resource_id is provided, filter by it
   - 422 for invalid boundary, 503 for database errors

2. `GET /api/series/{series_id}/revisions/{revision_id}` — get single revision
   - Query params: `visible_until_order` (required Boundary)
   - Returns `RevisionResponse`
   - 404 if not found or hidden
   - 422 for invalid boundary

3. `POST /api/series/{series_id}/revisions/{revision_id}/revert` — revert to revision
   - No request body
   - Returns `RevisionResponse` (the newly created REVERTED revision)
   - Business logic:
     a. Fetch the target revision (must exist and be visible)
     b. Determine the resource it references
     c. Verify the resource still exists and has origin='user' (for UPDATED reverts)
     d. If action=UPDATED: restore resource state from revision.before
     e. If action=DELETED: re-create the resource from revision.before (set all properties back)
     f. Create a new Revision with action=REVERTED, before=current snapshot, after=restored snapshot
     g. Return the new revision
   - 404 if revision not found
   - 409 if resource is canonical/candidate (not user-owned)
   - 422 if action=CREATED (can't revert a create)
   - 503 for database errors

**Cypher queries** in `backend/app/revisions/__init__.py`:

```python
REVISION_LIST_QUERY = """
MATCH (revision:Revision {series_id: $series_id})
WHERE revision.visible_from_order IS NOT NULL
  AND revision.visible_from_order >= 1
  AND revision.visible_from_order <= $visible_until_order
  AND ($resource_type IS NULL OR revision.resource_type = $resource_type)
  AND ($resource_id IS NULL OR revision.resource_id = $resource_id)
RETURN revision.id AS id, revision.series_id AS series_id,
  revision.resource_type AS resource_type, revision.resource_id AS resource_id,
  revision.action AS action, revision.before AS before,
  revision.after AS after, revision.visible_from_order AS visible_from_order,
  revision.created_at AS created_at
ORDER BY revision.created_at DESC, revision.id ASC
"""
```

```python
REVISION_REVERT_UPDATED_QUERY = """
MATCH (revision:Revision {id: $revision_id, series_id: $series_id})
MATCH (resource {id: revision.resource_id, series_id: $series_id})
WHERE resource.origin = 'user'
  AND revision.visible_from_order IS NOT NULL
  AND revision.visible_from_order >= 1
  AND revision.visible_from_order <= $visible_until_order
WITH revision, resource, resource.visible_from_order AS origin_vfo
SET resource = $restored_state,
    resource.visible_from_order = origin_vfo,
    resource.origin = 'user'
RETURN resource.id AS id, labels(resource) AS labels, properties(resource) AS props
"""

REVISION_REVERT_DELETED_QUERY = """
MATCH (revision:Revision {id: $revision_id, series_id: $series_id})
WHERE revision.action = 'Deleted'

  AND revision.visible_from_order >= 1
  AND revision.visible_from_order <= $visible_until_order
  AND revision.before IS NOT NULL
WITH revision, revision.before AS before_snapshot
// Re-create the node from the before snapshot

  series_id: before_snapshot.series_id,
```
