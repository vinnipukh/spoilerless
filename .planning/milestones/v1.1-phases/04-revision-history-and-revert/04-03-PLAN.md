   - Create a note → verify a Revision exists with action=Created

   - Delete a note → verify a Revision exists with action=Deleted, before shows old content
   - Create/Update/Delete custom nodes → verify revisions logged
   - Create/Update/Delete custom relationships → verify revisions logged

   - List revisions returns all revisions for the series, ordered most-recent-first
   - Filter by resource_type
   - Filter by resource_id
   - Get single revision by ID returns correct data
   - Hidden revision (too recent boundary) returns 404
   - Non-existent revision returns 404

3. **Revert tests** (prove REV-03):
   - Revert an UPDATED note → content restored to before state, new REVERTED revision created
   - Revert a DELETED note → note re-appears with restored content, new REVERTED revision created
   - Revert shows before/after correctly in the new revision
   - Revert on a CREATED revision → 422
   - Revert on canonical resource → 409
   - Revert twice on same revision → both reverts succeed (idempotent at chain level)
   - History preserved after revert (original revision still exists)

4. **Spoiler boundary tests:**
   - Revision attached to S01E03-visible resource is not visible at boundary=1
   - Hidden revision returns same envelope as non-existent revision

5. **Existing behavior preservation:**
   - All previously passing user-content tests still pass after revision logging is enabled
