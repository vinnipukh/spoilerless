<objective>
Create the Revision domain model, Neo4j persistence layer, and integrate revision logging into every existing user-content mutation. This establishes the append-only history foundation before API endpoints.

All user-content mutations (note create/update/delete, custom-node create/update/delete, custom-relationship create/update/delete) must create a Revision record inside the same Neo4j write transaction.
</objective>

<threat_model>
- **Tampering (ASVS V5):** Revision `before`/`after` values are server-generated JSON snapshots, not client-submitted. No client can inject false history.
- **Info disclosure (ASVS V7):** Revisions for spoiler-hidden resources must not be visible at earlier boundaries. Filter by `visible_from_order` derived from the linked resource.
- **Denial of service (ASVS V5/V7):** Unbounded revision accumulation. Accept for prototype; production would need retention policies.
- **Integrity (ASVS V11):** Revisions must be append-only. No update/delete operations exist for Revision nodes.
</threat_model>

2. Method `log_revision(tx, series_id, resource_type, resource_id, action, before, after, visible_from_order)` — this is a static method designed to be called inside an `execute_write` callback. It creates a `Revision` node and a `REVISES` relationship to the target resource.

```python
REVISION_CREATE_QUERY = """
MATCH (resource {id: $resource_id, series_id: $series_id})
WHERE resource.visible_from_order IS NOT NULL
  AND resource.visible_from_order >= 1
CREATE (revision:Revision {
  id: $id,
  series_id: $series_id,
  resource_type: $resource_type,
  resource_id: $resource_id,
  action: $action,
  before: $before,
  after: $after,
  visible_from_order: resource.visible_from_order,
  created_at: $created_at
})
CREATE (revision)-[:REVISES {
  id: $id + ':revises',
  series_id: $series_id,
  visible_from_order: resource.visible_from_order,
  origin: 'user'
}]->(resource)
RETURN revision.id AS id, revision.series_id AS series_id,
  revision.resource_type AS resource_type, revision.resource_id AS resource_id,
  revision.action AS action, revision.before AS before,
  revision.after AS after, revision.visible_from_order AS visible_from_order,
  revision.created_at AS created_at
"""
```
