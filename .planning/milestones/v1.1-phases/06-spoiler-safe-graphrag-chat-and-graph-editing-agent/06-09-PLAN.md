<objective>
Build the visible chat surface: the DetailPanel's new Inspector/Chat mode toggle (making its Sheet
`open` state real for the first time in this codebase), the top-bar `ChatLauncher`, the compact session
picker, and the message list with streaming bubbles and citation chips — everything RAG-16 requires
except the ChangeSet preview card (06-11) and the graph-focus wiring (06-10).

existing DetailPanel Sheet, not a new surface — this is the highest-risk frontend integration point in
the phase because it changes a previously-always-open, always-Inspector component's contract for the
first time.
Output: `ChatLauncher.tsx`, `ChatPanel.tsx`, `SessionPicker.tsx`, `MessageList.tsx`, `MessageBubble.tsx`,
`CitationChip.tsx`, a stateful `DetailPanel.tsx` mode toggle, shadcn `textarea`/`scroll-area`.
