<objective>
Expand the tracer's single-tool retrieval layer into the full ten-tool allowlist and harden the
retrieval/context/citation pipeline into a fully spoiler-safe, injection-resistant, grounded-answer
system: complete tool coverage (RAG-02), fail-closed leakage prevention across every side channel
(RAG-03), bounded/deduplicated context building (RAG-05), hardened prompt-injection defenses beyond the
tracer's five basic cases (RAG-06), full citation grounding with insufficient-evidence handling
(RAG-07), and strict future-content non-confirmation (RAG-08).

Purpose: this is the security-critical core of the phase — the boundary that decides what an LLM is
ever allowed to see or say about the graph. It must be exhaustively leak-tested, not just happy-path
tested.
Output: `backend/app/retrieval/tools.py` with all ten allowlisted tools; a hardened
`backend/app/retrieval/pipeline.py`; a comprehensive leakage/citation/injection test suite.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM tool-call arguments -> retrieval tools | Model-chosen arguments (IDs, query strings, hop counts) are untrusted input to server-enforced tools |
| Retrieved context -> final answer prompt | Graph-sourced text is untrusted data even after retrieval; must not be reinterpreted as instructions |
| Model-cited IDs -> citation validator | The model's claimed citations are untrusted assertions requiring independent verification |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-02 | Information Disclosure | retrieval/tools.py (8 new tools) | critical | mitigate | Every tool independently re-applies visibility/series/cross-series/depth/count bounds server-side (Task 1) |
| T-06-06 | Tampering / Elevation of Privilege | retrieval/pipeline.py, llm/system_prompt.py | high | mitigate | Context sections remain delimited and data-framed even under dedup/reordering/bounding changes (Task 2) |
| T-06-09 | Information Disclosure | retrieval/pipeline.py | medium | mitigate | Citation validator checks this-turn retrieval membership, rejecting both hidden and real-but-unretrieved IDs (Task 3) |
| T-06-13 | Denial of Service | retrieval/pipeline.py | medium | mitigate | Context size/round bounds enforced regardless of tool-call concurrency (Task 2) |
</threat_model>
