<objective>
Prove the entire spoiler-safe GraphRAG backend architecture end-to-end on ONE real, production-quality
vertical slice before expanding into the full retrieval-tool set, the ChangeSet agent, and the frontend:
a user asks a question, the backend resolves their persisted watch-progress boundary, calls one
allowlisted retrieval tool (`get_neighborhood`) against real Neo4j data, streams a grounded answer back
with a citation validated against what was actually retrieved this turn, and persists the exchange as a
`ChatSession`/`ChatMessage` pair carrying the exact boundary used.

Purpose: this is the tracer bullet for the whole phase (TRACER_MODE). Every subsequent plan
(06-02..06-11) extends pieces this plan creates — the LLM provider abstraction, the progress-resolution
pattern, the retrieval-tool shape, the citation-validation shape, and the chat persistence/streaming
contract. Getting this slice right, and proving it with a real integration test against a real local
Neo4j instance (no mocked browser, no mocked DB), de-risks everything that follows.
Output: a working `POST /api/series/{series_id}/chat/sessions/{session_id}/messages/stream` endpoint
that answers a real question about seeded Dexter S01E01-03 data, with `LLM_ENABLED`/provider abstraction,
persisted watch progress, one retrieval tool, and citation-validated streamed responses.
</objective>
