<objective>
Build the frontend's typed data layer for chat, progress, and ChangeSet consumption: TypeScript types
matching the backend's locked response shapes, API client functions following the existing `apiFetch`
convention (plus a dedicated streaming client function `apiFetch` cannot serve), and React hooks
managing session/message/streaming state.

Purpose: this is the foundation every subsequent frontend plan (06-09, 06-10, 06-11) builds UI on top
of. Getting the streaming-state shape and type fidelity right here means the UI plans can focus purely
on rendering, not data-fetching correctness.
Output: `types/chat.ts`, `types/changeSet.ts`, `api/chat.ts`, `api/changeSet.ts`, `api/progress.ts`,
`useChatSessions.ts`, `useChatMessages.ts`, `test/fixtures/chatFixtures.ts`.
</objective>
