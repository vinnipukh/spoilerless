<objective>
Wire two RAG-17/RAG-01 capabilities that both live at the App.tsx composition root and both extend
GraphCanvas: make `useWatchProgress` actually call the new backend progress endpoint (completing RAG-01
on the frontend), and give `GraphCanvas` an externally-driven `focusedElementIds` prop plus a
`GraphFocusIndicator` overlay so a chat citation's "Show in graph" action can highlight the relevant
subgraph without destroying the user's current view.

Purpose: `GraphCanvas`'s Cytoscape instance has never been controllable from outside itself before this
phase — this is a genuine new capability, not an additive prop, and must not break the existing
tap-to-select interaction it already owns. `useWatchProgress` has never called the backend before this
phase — RAG-01 is incomplete without this half.
Output: a backend-aware `useWatchProgress.ts`, a `focusedElementIds`-driven `GraphCanvas.tsx`, and
`GraphFocusIndicator.tsx`.
</objective>
