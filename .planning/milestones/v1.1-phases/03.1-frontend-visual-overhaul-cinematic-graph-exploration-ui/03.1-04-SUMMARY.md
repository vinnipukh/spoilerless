# Phase 03.1 Plan 04 — Summary

## GraphLegend + GraphControls Overlays

**Status:** Complete — verified via conversational UAT
**Duration:** ~3 min (2 tasks)

### Delivered

| Task | Description | Files |
|------|-------------|-------|
| T1 | shadcn tooltip/collapsible primitives + collapsible GraphLegend | `tooltip.tsx`, `collapsible.tsx`, `GraphLegend.tsx`, `GraphCanvas.tsx` |
| T2 | GraphControls (zoom in/out/fit/reset) wired to existing cy instance | `GraphControls.tsx`, `GraphCanvas.tsx` |

### Key Outcomes

- `tooltip.tsx` and `collapsible.tsx` created (Radix UI primitives)
- GraphLegend: bottom-left, collapsed by default, toggle with aria-expanded/aria-label
- Legend sections: Node Types (8 types with color+shape swatches), Relationships (grouped by color family), Forward-compatible (de-emphasized zero-instance groups)
- Legend colors sourced from `relationshipStyles.ts` — not duplicated (EDGE_TYPE_TO_FAMILY + FAMILY_HEX)
- GraphControls: bottom-right, 4 icon buttons (ZoomIn, ZoomOut, Maximize2, RotateCcw)
- Each control: 44×44px hit area, tooltip via shadcn Tooltip, aria-label matching tooltip text
- Zoom in/out: `cy.zoom()` with 1.2× factor, bounds clamped by existing minZoom/maxZoom
- Fit: `cy.fit(undefined, 48)`
- Reset: reuses existing `runLayout` function — not a second code path
- Controls read `cyRef.current` at click time (not render time)
- Both overlays positioned `fixed` with `z-[60]` to stay above the DetailPanel Sheet (which renders `fixed z-50` in a portal)
- Both overlays rendered inside GraphCanvas's graph-canvas-backdrop wrapper

### Verification

- `npm run build` — clean
- `npm run lint` — clean
- Conversational UAT: tests 13-14 pass (legend toggles, controls visible, tooltips work)

### Decisions

- `fixed` positioning with `z-[60]` instead of `absolute z-10` — necessary because SheetContent renders `fixed z-50` in a portal and would otherwise cover bottom-right controls
- GraphControls reset calls the same module-scope `runLayout` function from GraphCanvas.tsx — avoids duplicating layout code
- Legend rows are static (not independently focusable) — only the toggle button is a tab stop
