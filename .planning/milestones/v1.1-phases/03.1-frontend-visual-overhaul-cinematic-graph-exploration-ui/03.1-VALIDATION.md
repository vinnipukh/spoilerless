## Sampling Rate

- **After every task commit:** Run `npm run test -- --run <changed-file>.test.tsx` (targeted)
- **After every plan wave:** Run `npm run test -- --run` (full suite) + `npm run lint` + `npm run build` (runs `tsc -b` first — also the typecheck gate)
- **Before `/gsd-verify-work`:** Full suite green + lint clean + build clean
- **Max feedback latency:** ~20 seconds (full suite + build)
