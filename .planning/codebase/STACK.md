# Codebase Stack

## Summary

`hdgrafcehennemi` is a small brownfield prototype with three visible surfaces:

1. A Python/FastAPI backend under `backend/app/`.
2. A React/Vite frontend under `frontend/`.
3. A standalone static marketing/prototype page at root `index.html`.

The backend is the most project-specific code. The frontend still appears mostly scaffolded from the Vite React template, while `index.html` contains a much more complete Turkish landing/demo prototype for the product concept.

## Python Backend

- Root manifest: `pyproject.toml`.
- Project name/version: `hdgrafcehennemi` `0.1.0`.
- Declared Python requirement: `>=3.13` in `pyproject.toml`.
- Main backend app: `backend/app/main.py`.
- API framework: `fastapi>=0.140.7`.
- Runtime server: `uvicorn[standard]>=0.51.0`.
- Data validation/config: `pydantic-settings>=2.14.2`, `python-dotenv>=1.2.2`.
- Graph database driver: `neo4j>=6.2.0`.
- Dev tools in dependency group: `pytest>=9.1.1`, `httpx>=0.28.1`.
- Exported backend lock-style requirements: `backend/requirements.txt`, generated by `uv export`.

## Backend Runtime Shape

- `backend/app/main.py` constructs a FastAPI app with title `HD Graf Cehennemi API`.
- The app uses a lifespan hook that verifies Neo4j connectivity on startup and closes the driver on shutdown.
- `backend/app/api/series.py` registers API routes under `/api/series`.
- `backend/app/domain/series.py` defines Pydantic response models.
- `backend/app/graph/database.py` owns the global Neo4j driver singleton.
- `backend/app/graph/seed.py` seeds graph data from `data/dexter/metadata/`.

## Frontend

- Frontend manifest: `frontend/package.json`.
- Build system: Vite `^8.1.1`.
- UI runtime: React `^19.2.7`, React DOM `^19.2.7`.
- Graph visualization dependencies: `cytoscape ^3.34.0` and `react-cytoscapejs ^2.0.0`.
- Language/tooling: TypeScript `~6.0.2`, ESLint `^10.6.0`, `typescript-eslint ^8.62.0`.
- Entry point: `frontend/src/main.tsx`.
- Root component: `frontend/src/App.tsx`.
- Config: `frontend/vite.config.ts`, `frontend/tsconfig*.json`, `frontend/eslint.config.js`.

## Static Prototype

- Root `index.html` is a large self-contained static page in Turkish.
- It includes extensive inline CSS and product UI copy for `HD Graf Cehennemi`.
- It appears to represent the product vision more directly than the current Vite app.

## Data Files

- `data/dexter/metadata/series.json` contains a single Dexter series record.
- `data/dexter/metadata/episodes.json` contains initial episode metadata for Dexter season 1 episodes 1-3.

## Tooling Notes

- `.gitignore` excludes `.env`, virtualenvs, Node build outputs, Neo4j local data/log/plugin/import folders, IDE folders, and OS files.
- There is no Docker Compose file checked in for Neo4j.
- There is no visible CI configuration under `.github/`.
- There is no backend test tree currently visible.
