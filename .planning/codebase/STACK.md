# Codebase Stack

## Summary

`hdgrafcehennemi` ("HD Graf Cehennemi") is a spoiler-safe narrative knowledge graph prototype (Dexter S01E01-03) with two active surfaces:

1. A Python/FastAPI backend under `backend/app/` — series/episode/graph read APIs, Google-Sign-In auth + sessions, user content (notes/watch progress), revision history, and a backend-only candidate extraction/review pipeline (Phase 5).
2. A React/Vite frontend under `frontend/` — Cytoscape.js graph canvas, shadcn/ui component library, spoiler-boundary episode navigation, notes/detail panel, and revision history UI.

The root static `index.html` prototype page noted in the prior snapshot is no longer present; the product is now fully implemented across the two app surfaces. v0 milestone (Phases 1-4, plus backend-only Phase 5 future-extraction prep) has shipped and archived. A new Phase 05.1 (candidate review frontend UI) is queued next — there is currently no frontend UI for reviewing/ingesting extraction candidates, only backend APIs and repository logic.

## Backend Runtime Shape

- `backend/app/main.py` constructs a FastAPI app titled `HD Graf Cehennemi API`, version `0.1.0`.
- Lifespan hook opens a `Neo4jDatabase` instance, attaches it and an in-memory/Neo4j session repo to `app.state`, attempts connectivity verification (non-fatal — degraded startup is intentional so `/health` reports live status), and closes the driver on shutdown.
- `/health` endpoint reports `{status, database, service}` and returns 503 when Neo4j is unavailable.
- CORS origins are now driven by `settings.frontend_origins` (comma-separated, default `http://localhost:5173`) rather than hardcoded, with `allow_credentials=True` (required for the session cookie).
- Routers registered: `series_router`, `graph_router`, `user_content_router`, `auth_router`, `revision_router`, `candidates_router` — six route modules under `backend/app/api/`.

**API modules (`backend/app/api/`):**
- `series.py` — `/api/series` series/episode listing.
- `graph.py` — spoiler-boundary-filtered graph read endpoint(s).
- `user_content.py` — notes and watch-progress endpoints.
- `auth.py` — `/api/auth` Google Sign-In verification, session cookie issuance, logout, CSRF-style origin/referer verification.
- `revisions.py` — `/api/series/{series_id}/revisions` revision history read endpoints, spoiler-boundary filtered.
- `candidates.py` — `/api/series/{series_id}/candidates` extraction-candidate ingest, list, get, edit, and review-decision endpoints (backend-only; no frontend UI yet).

**Domain/service/repository layers:**
- `backend/app/domain/` — Pydantic models: `series.py`, `graph.py`, `auth.py`, `user_content.py`, `revision.py`, `extraction.py` (candidate/claim ingest contract, ontology-validated).
- `backend/app/services/` — `auth.py` (Google token verification via `google-auth`), `graph.py`, `series.py`.
- `backend/app/repository/` — `session.py` (session storage), `user.py`, `user_content.py`.
- `backend/app/graph/` — `database.py` (Neo4j driver singleton/dependency), `seed.py` (metadata seeding), `setup.py` (constraint/index setup, CLI entrypoint), `candidates.py` (candidate claim repository), `ontology.py` (loads and validates `ontology/*.yaml` allowlists for claim types, predicates, confidence levels, relationship effects).
- `backend/app/revisions/` — revision repository (audit trail for structural/content edits).
- `backend/app/spoiler/filter.py` — spoiler-boundary filtering logic shared by graph/revision reads.
- `backend/app/core/config.py` — `Settings` (pydantic-settings): Neo4j connection, Google OAuth client ID, session cookie name/TTL/secure flag, `frontend_origins`.
- `backend/app/core/errors.py` — shared error-envelope (`{detail: {code, message}}`) and database error handlers.

**Backend tests (`backend/tests/`):** `test_auth.py`, `test_candidate_ingest.py`, `test_candidate_review.py`, `test_extraction_models.py`, `test_frontend_contract_doc.py`, `test_graph_api.py`, `test_openapi_contract.py`, `test_revision_models.py`, `test_revisions.py`, `test_seed_idempotency.py`, `test_user_content_api.py`, `test_user_content_models.py`, `test_user_content_repository.py`. Prior snapshot noted "no visible backend test tree" — this is now a substantial test suite (12 files).
