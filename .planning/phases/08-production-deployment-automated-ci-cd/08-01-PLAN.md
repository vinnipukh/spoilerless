<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser <-> Vercel (static) | Public internet, TLS-terminated by Vercel |
| Browser <-> Render (API) | Public internet, TLS-terminated by Render, cross-subdomain of the same custom domain |
| Render <-> AuraDB | TLS (neo4j+s://), credentialed with a least-privilege Member-role user |
| Local dev environment <-> committed repo | `.env`/`.env.local` must never cross this boundary |
