Ship the three navigation/discovery features as one shared implementation:
node search (FEAT-01), full-text notes & claims search (FEAT-07), and the
command palette (FEAT-08 — which is also FEAT-11.3's quick-switcher, one

action rides the PROB-31-fixed requestChange (09-07), routing locked episodes
to the unlock dialog.

highest-frequency interaction gap in the current graph-first UI.

and the shared searchIndex — all vitest-covered.
</objective>
