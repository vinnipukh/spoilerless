<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Anonymous visitor <-> share read route | Token-gated; no session; stored boundary only |
| Token store <-> Neo4j | Hash at rest, raw token returned once |
| ShareView <-> AppShell | Read-only shell must expose no write surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-12-01 | Information Disclosure | Share link becoming a second looser spoiler path | critical | mitigate | Read route calls the SAME fetch_graph assembly with the stored boundary; client-chosen boundary ignored (D-09, test-asserted) |
| T-09-12-02 | Tampering | Raw token theft from at-rest storage | high | mitigate | sha256 hash only; raw token returned once (V6) |
| T-09-12-03 | Tampering | Stale share links past expiry | medium | mitigate | expires_at default 30d + sweep + read-time rejection |
| T-09-12-04 | Elevation of Privilege | Revoke by non-creator | medium | mitigate | DELETE scoped to creator/admin (CurrentUserDependency) |
| T-09-12-05 | Tampering | Constraint addition breaking seed suite | medium | mitigate | Superset assertion updated in the same plan (Pitfall 2) |
| T-09-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | stdlib secrets/hashlib only; no new dependencies |
</threat_model>
