## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding, inline chip spacing |
| sm | 8px | Compact element spacing, node-type legend items, form field gaps |
| md | 16px | Default element spacing, card padding, panel section gaps |
| lg | 24px | Section padding (detail panel body, modal body) |
| xl | 32px | Layout gaps (canvas ↔ side panel gutter, header height padding) |
| 2xl | 48px | Major section breaks (top bar height) |
| 3xl | 64px | Page-level spacing (unused unless a landing/empty full-page state is needed) |

Exceptions:
- Cytoscape canvas zoom/pan control buttons: 44×44px minimum touch target (icon-only controls), per standard touch-target accessibility floor — overrides the 4px-multiple aesthetic scale for hit-area only, not visual padding.
- Node/edge canvas layout spacing is controlled by the `cose-bilkent` (or `cose`, if `cose-bilkent` proves unstable — see fallback below) force-directed layout engine, not the 8-point scale — the scale governs UI chrome (panels, headers, modals) only.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.5 — used for badges, node-type legend, metadata captions (episode locator, confidence level) |
| Heading | 18px | 600 (semibold) | 1.2 — panel section titles, modal title |
| Display | 24px | 600 (semibold) | 1.2 — top bar series/episode title only |

Rationale for smaller-than-default body size (14px vs the template's usual 16px default): this is a data-dense graph-inspection tool (detail panel, evidence locators, claim metadata) where information density in the side panel matters more than large reading type; 14/12/18/24 is a tight, tool-like scale consistent with the "developer-tool" dark-indigo palette direction already confirmed.

Font family: Geist Variable for all four roles (no separate heading font) — variable weight axis supplies both 400 and 600 without extra font files.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0F172A` (`--background`) | App shell background, canvas background, page chrome |
| Secondary (30%) | `#192134` (`--card`) | Detail panel surface, modal/dialog surface, top bar surface, card backgrounds |
| Accent (10%) | `#7C3AED` (`--accent`) | Selected-node ring/glow on canvas, active episode tab indicator, active tab underline, focus rings on interactive controls |
| Primary interactive | `#4338CA` (`--primary`) | Primary CTA buttons ("Confirm & Unlock S01E0X"), primary button backgrounds, default `--ring` |
| Secondary interactive | `#6366F1` (`--secondary`) | Secondary buttons, hover states on primary-adjacent controls, edge-highlight color on hover/selection |
| Warning (spoiler confirmation) | `#F59E0B` (`--warning`, custom token) | Spoiler-confirmation modal icon/border/badge ONLY — never used for delete/destroy actions |
| Destructive | `#DC2626` (`--destructive`) | Destructive actions only (none exist yet in Phase 2 scope — reserved for Phase 3+ delete-note/delete-edit flows; not wired to any Phase 2 control) |
| Muted foreground | `#94A3B8` | Secondary/help text, disabled states, unselected legend items, muted metadata (timestamps, locators) |
| Foreground | `#FFFFFF` | Primary text on all dark surfaces |
| Border | `rgba(255,255,255,0.08)` | Card/panel/input borders, canvas viewport border |

Accent (`#7C3AED`) reserved for: selected-node ring on the Cytoscape canvas, the active episode indicator in the top episode selector, and the active-tab underline in the detail panel (character/claims/evidence tabs). It must NOT be used for default button fills, default badges, or unselected/idle UI — that would dilute the reserved-for-selection meaning per the 10% rule.

Warning (`#F59E0B`) is a third, distinct semantic color — deliberately separate from primary indigo and destructive red — reserved exclusively for the spoiler-confirmation modal (icon, border accent, "Yes, unlock episode" button uses warning-tinted styling, not destructive-red styling) because advancing watch progress is an intentional, irreversible-but-safe action, not a destructive delete.

Node-type / origin visual mapping (Cytoscape canvas, not the 60/30/10 chrome palette — the graph canvas uses its own semantic mapping per node `type`/`origin` fields):

| Node type | Shape |
|-----------|-------|
| Character | circle |
| Event | rounded rectangle |
| Location | square / rounded square |
| Organization | diamond |
| UserNote | dashed-border note shape (out of Phase 2 scope — Phase 3, but shape reserved now for forward compatibility) |

| Origin | Border treatment |
|--------|-------------------|
| curated | solid border |
| automatic | standard border + small system-indicator glyph (out of Phase 2 seed scope — all Phase 1 seed data is `curated`; treatment reserved for Phase 5) |
| user | dashed border (Phase 3 scope, reserved) |

Node fill color uses `--muted` (`#131936`) as the idle/unselected fill across all node types (shape carries the type distinction, not color, to avoid a second competing color-coding system); selected node fill lightens toward `--card` with the `--accent` ring; edges use `--border` idle / `--secondary` on hover-or-selected.

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's
> `## UI Considerations` lift rule via the identical rule as SPEC `## Edge Coverage`. Shape-rooted UI *state*
> coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).
> Empty-state and error-state COPY live in `## Copywriting Contract` above — this section covers
> state coverage and REFERENCES those rows rather than restating the copy (de-dup).

Applicable state considerations resolved: 7 covered, 3 backstop, 1 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Cytoscape graph canvas (list-collection) | ✅ covered | Zero-node response at a given episode order renders the "Nothing revealed yet" empty state defined in Copywriting Contract |
| loading | Cytoscape graph canvas, episode selector (list-collection, nav) | 🧪 backstop | `Skeleton` component (already installed) renders over the canvas/panel region while `/api/graph` is in flight; no explicit loading-state test exists yet — held out for the plan-phase test wiring |
| error | Cytoscape graph canvas, episode selector (list-collection, nav) | ✅ covered | Fetch failure renders the "Couldn't load the graph" error copy + Retry button defined in Copywriting Contract |
| populated | Cytoscape graph canvas (list-collection) | ✅ covered | Happy-path target is 8–15 visible nodes per episode per the coding-agent spec; layout engine (`cose-bilkent`/`cose`) keeps this readable at that volume |
| partial | Node detail panel — Claims/Evidence tabs (list-collection) | ✅ covered | A node with zero linked claims or zero evidence fragments renders "Select a node to see details."-style empty sub-state per tab (e.g. "No claims recorded for this node yet") rather than a blank panel |
| overflow | Node detail panel — Evidence tab locator text (static-content) | 🧪 backstop | Long evidence `text` fields wrap and scroll within the panel's fixed-height evidence card rather than expanding the panel indefinitely — no explicit overflow test yet, held out for plan-phase |
| zero-one-many | Cytoscape graph canvas (list-collection) | ✅ covered | Singular episode-boundary language ("Nothing revealed yet" at zero, no special-cased singular/plural node-count copy needed since the canvas never displays a numeric node count in-UI) |
| long-text | Character/claim labels, evidence locator strings (static-content) | ⚠ unresolved | No truncation rule specified for unusually long character names or claim labels on canvas node labels — planner should treat single-line ellipsis truncation with full text on hover-tooltip as the default assumption unless UAT surfaces a real long-label case in the Dexter S01E01-03 seed data |
| loading | Node detail panel on node click (interactive-control) | 🧪 backstop | Panel shows `Skeleton` placeholders for claim/evidence rows while node-detail data resolves from already-fetched graph payload (should be near-instant client-side, not a network round trip) — held out, no explicit test |
| empty | Node detail panel — no node selected (static-content) | ✅ covered | Renders "Select a node to see details." placeholder copy |
| overflow | Top episode selector (nav) | ✅ covered | Only 3 episodes (S01E01–03) exist for Prototype v0 — a `Select`/`Tabs` control at that count never overflows; no scroll/wrap behavior needed |
